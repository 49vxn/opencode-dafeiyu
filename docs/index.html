A field study of the desk whale

A small whalefor a long build.

It sits in the corner of your screen and shows what your coding agent is doing — not what a timer guesses. It reads Freebuff, opencode and Claude Code read-only, then picks one of eighty-nine animations to match the actual work.

    The vocabulary

    Every animation answers a real event. Nothing here is a loop waiting for a reason — if the agent does it, the whale has a face for it.

    preview
    idle nothing is running
    hover a row 8 frames · 6 fps · loop

    Hover any row to run it on the whale. Chonk variants resolve automatically once it has been fed.

    02

    It sleeps
    when you do.

    Six of the eighty-nine only happen when you are gone. It dozes, it wanders, it comes back when you do — and nothing here is a screensaver. Each of these is triggered by the clock on your machine, not the agent's.

    Drift states · triggered by system idle time

    03

    How it knows

    Three local adapters, opened read-only. Nothing is uploaded, and no adapter can write to the agent's database.

    Freebuff ~/.config/freebuff-desktop/projects/*/desktop-v2.db sqlite
    opencode ~/.local/share/opencode/opencode.db sqlite
    Claude Code ~/.claude/projects/*/*.jsonl jsonl

    Any other harness

    A tool that can run a shell command doesn't need an adapter at all. Push the state directly — it holds for a minute, then sampling takes over again. 

    curl -X POST --data-binary \
  '{"state":"running-cmd","detail":"the tests"}' \
  http://127.0.0.1:8791/event
    04

    Install

    One click, per user, no admin prompt. It starts with Windows and lives in the tray.

    dafeiyu-Setup-0.4.6.exe

    Windows 10 / 11, 64-bit · 108 MB
    installs to %LOCALAPPDATA%\Programs\dafeiyu

    Unsigned. SmartScreen will warn the first time — More info → Run anyway. Signing needs a certificate.

    Uninstall is the normal Windows route; it removes the app, its data and its startup entry.

    macOS is in progress. The adapters are already portable; the window and packaging are not.
